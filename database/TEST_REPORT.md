## ما اختُبر فعليًا

إنشاء الجداول والبيانات المرجعية وفصل الإنتاج عن التجربة؛ صحة hash المستخدم التجريبي وصلاحياته؛ المفاتيح الأجنبية والقيود والأشجار والوحدات والدفعات؛ حفظ وتعديل المسودة بلا أثر مالي؛ شراء وبيع نقدي وآجل، والضريبة والخصم وتكلفة المبيعات؛ مردود البيع والشراء وحدود الكميات والتكلفة الأصلية والتقريب؛ سندات قبض وصرف وتوزيع سند على عدة فواتير؛ منع التجاوز والطرف الخاطئ؛ توازن القيود اليدوية والمولدة؛ مطابقة حساب المخزون لقيم الحركات وتوازن الدفتر؛ المخزون السالب والفترة المغلقة وفصل المستودعات والدفعات والفروع؛ حماية المستندات والأسطر والحركات والتدقيق بعد الترحيل.

حُقن خطأ متعمد في آخر مرحلة من ترحيل فاتورة بعد إنشاء المخزون والقيد؛ عادت الحالة والتكلفة والحركات والقيد والتدقيق جميعًا دون أثر جزئي. وعند محاولة الترحيل من اتصالين متزامنين نجح أحدهما ورُفض الآخر مع أثر مالي واحد.

اختُبر إغلاق اتصال قاعدة محفوظة على القرص وإعادة فتحها وبقاء البيانات، وتفعيل FK عند الفتح الجديد. هذا اختبار SQLite محلي، وليس ادعاء اختبار إغلاق عملية Android. اختُبر التحديث 1→2 مع حفظ البيانات، وإعادته بلا تكرار، ورفض تخفيض الإصدار وتغيير checksum، والتراجع عند فشل تحديث، ورفض القواعد القديمة غير المرقمة دون فقدان بياناتها. أُضيف فحص لجدول `android_metadata` الداخلي كي لا يمنع التهيئة الأولى.

## Flutter وAndroid

| الفحص | النتيجة الفعلية |
|---|---|
| 14 ملف Dart: توازن الأقواس والسلاسل والتعليقات | نجح فحص بنيوي محلي فقط |
| 6 ملفات Android XML وحزمة JSON ومغلّف Gradle | نجح الفحص المحلي؛ لا يعني نجاح البناء |
| Flutter SDK وDart SDK | غير مثبتين |
| Android SDK وadb وemulator | غير متاحة في المسارات المفحوصة |
| Java | OpenJDK 21.0.13 متاح |
| `/dev/kvm` | غير موجود |
| `flutter pub get` و`flutter analyze` | **لم ينفذا** |
| اختبارات Flutter الستة للوحدات والـrepository والواجهة | **مضافة، لم تشغّل** |
| اختبار تكامل Android | **مضاف، لم يشغّل** |
| APK | **لم يُبنَ** |
| تشغيل التطبيق على محاكي/هاتف أو فحص logcat | **لم ينفذ** |

| GitHub Actions | workflow مضاف، لم يشغّل في هذه الجلسة |
