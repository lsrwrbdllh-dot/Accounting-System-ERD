## الأثر المالي

| العملية | المدين | الدائن |
|---|---|---|
| مشتريات | المخزون بالقيمة الصافية + ضريبة المدخلات | الصندوق أو المورد بالإجمالي |
| مبيعات | الصندوق أو العميل بالإجمالي؛ تكلفة المبيعات بالتكلفة | المبيعات الصافية + ضريبة المخرجات؛ المخزون بالتكلفة |
| مردود مبيعات | مردود المبيعات + ضريبة المخرجات؛ المخزون بتكلفة الأصل | الصندوق أو العميل؛ تكلفة المبيعات |
| مردود مشتريات | الصندوق أو المورد؛ فرق التكلفة عند الحاجة | المخزون بالقيمة الدفترية + ضريبة المدخلات؛ فرق التكلفة عند الحاجة |
| قبض | الصندوق | الحسابات في تفاصيل السند |
| صرف | الحسابات في تفاصيل السند | الصندوق |
| قيد يدوي | الحسابات الفرعية المدخلة | الحسابات الفرعية المدخلة، مع تحقق التوازن |

الترحيل لا يعتمد على الواجهة. يمنع INSERT مباشر بحالة Posted. أثناء UPDATE من Draft إلى Posted تُحسب التكاليف ويُنشأ المخزون والقيد ويُرحّل القيد ويُسجل التدقيق. أي RAISE يعيد الجملة كلها، وطبقة التطبيق تحيط العملية بمعاملة إضافية. الحمايات تتحقق من الأب القديم والجديد عند نقل سطر، لتفادي نقل سطر مسودة إلى مستند مرحّل.

التكلفة حسب ترتيب الترحيل، ولا يسمح بالرجوع بتاريخ المخزون إلى ما قبل آخر مستند مرحّل في المستودع. أسعار الوحدة والتعبئة المستخدمة لا تتغير بعد استعمالها. فروق تقريب تكاليف الأسطر المتكررة والمرتجعات الجزئية توزّع تراكميًا لمنع بقاء قيمة مع كمية صفرية.

## حدود معتمدة لهذه النسخة

جداول التوسع موجودة دون ادعاء واجهات أو ترحيل للتحويلات والجرد وتسويات المخزون. لا يوجد استرداد نقدي لفاتورة آجل مسددة، أو تحويل عملات، أو ترحيل بأثر رجعي، أو إقفال سنوي آلي، أو طباعة ضريبية محلية. التصحيح التشغيلي المتاح للفواتير هو المرتجع؛ عكس سند أو قيد يحتاج مسارًا مستقلًا، والحذف/التعديل المباشر للمرحّل مرفوض.

سجل الصندوق يبدأ بصفر ولا ينشئ البرنامج رأس مال وهميًا. أدخل الرصيد الافتتاحي بقيد مالي قبل الاستخدام الفعلي. لا تفرض النسخة منع رصيد نقدي دائن؛ منع السالب مفروض على المخزون. توزيع مراكز التكلفة والافتتاحيات متحقق على مستوى SQL، دون شاشات مخصصة.

لم ينفذ محوّل للقاعدة SQL القديمة غير المرقمة، ولا تُحذف بياناتها أو تعاد تهيئتها عند فتحها. التحديثات المرقمة الجديدة مدعومة ومختبرة بين الإصدارين 1 و2، بما فيها التراجع عند فشل تحديث.
