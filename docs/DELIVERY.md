# قائمة التسليم

| المسار | ما تم إنشاؤه أو تعديله |
|---|---|
| `database/schema.sql` | استبدال المخطط الأولي بملف إنشاء موحد مولّد يضم الجداول والقيود والفهارس والترحيل والبيانات المرجعية وسجل التحديثات |
| `database/migrations/` | إصدار 1 للجداول، وإصدار 2 للسلامة والعروض والترحيل؛ 40 جدولًا مع سجل التحديثات |
| `database/seeds/production.sql` | دليل الحسابات والوحدات والأنواع والصندوق والمستودع والفترة والسنة والصلاحيات دون بيانات تجربة |
| `database/seeds/demo.sql` | مستخدم تجريبي وعميل ومورد وصنفان ووحداتهما في قاعدة منفصلة |
| `database/runtime.py`, `database/cli.py` | اتصالات FK، تحديثات ذرية محفوظة التحقق، وخدمة حفظ وترحيل وأداة إنشاء وفحص |
| `database/legacy/` | حفظ SQL والتقرير القديمين دون اعتبار نتائجهما نتائج التنفيذ الجديد |
| `database/TEST_REPORT.md`, `reports/` | التقرير الجديد ونتائج الآلة وسجل الاختبارات الفعلي |
| `app/lib/data/` | فتح SQLite وإصداراتها والتحقق من الحزمة، الدخول والصلاحيات وعمليات التطبيق الحقيقية |
| `app/lib/core/` | قراءة وكتابة الكسور الثابتة للمبالغ والكميات دون float |
| `app/lib/ui/`, `app/lib/main.dart` | دخول وإعداد مدير، رئيسية، حسابات، أصناف ووحدات، فواتير ومرتجعات، سندات وتخصيصات، قيود ومخزون |
| `app/assets/database.json` | نفس تعليمات SQL كتحديثات وبيانات أولية، مع SHA-256 لكل ملف |
| `app/android/` | مشروع Android Kotlin/Gradle، Manifest وموارد ومغلّف Gradle 8.11.1 الرسمي |
| `app/test/`, `app/integration_test/` | اختبارات Flutter لوحدات الكسور وrepository والواجهة، واختبار SQLite على Android؛ مضافة ولم تُشغّل هنا |
| `tests/test_accounting.py` | 58 اختبارًا آليًا على SQLite الحقيقية، تغطي حالات النجاح والخطأ والتزامن والتحديثات |
| `tools/` | توليد المشغلات وحزمة SQL، وفحص بنية الملفات، وتشغيل الاختبارات وحفظ النتائج |
| `docs/SOURCE_MANIFEST.json` | مصدر ثابت وبصمات جميع الملفات الأصلية |
| `docs/IMPLEMENTATION_REVIEW.md` | تحليل دمج المخططات والتعارضات وقرارات المحاسبة وحدود التنفيذ |
| `README.md`, `.github/workflows/verify.yml`, `.gitignore` | تعليمات التشغيل والتحقق وCI وتجاهل قواعد المستخدم وملفات البناء |

مخططات 00–12 لم تُعدّل. لم يُحذف أي جدول أصلي. لا تحفظ قواعد المستخدم الثنائية في Git؛ تُنشأ بالـCLI أو بالتطبيق. الملفات محفوظة في نسخة المستودع المحلية. لا يفيد هذا التسليم أن التعديلات دُفعت إلى GitHub أو أن CI شُغّلت هناك.

لم ينفذ: تشغيل محاكي أو هاتف، بناء APK، حل حزم Flutter، تحليل Dart، أو اختبارات Flutter؛ الأدوات غير مثبتة، ومحاولة تنزيلها لم تكتمل بسبب اتصال الشبكة من بيئة العزل وإلغاء طلب المحاولة الموسعة. يوضح README الخطوات المطلوبة خارج البيئة. فحص توازن الأقواس وXML وJSON لا يثبت صحة ترجمة Dart أو سلوك واجهاته.
